# UI Polish (Soft/Premium Dual Theme) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the UI feel soft, clean, smooth, lightweight and premium — by adding a switchable warm-light theme alongside the existing warm-dark theme (default), softening easing/radii/hover/focus, and animating panel toggles.

**Architecture:** CSS-variable theming via a `data-theme` attribute on `<html>`. `styles.css` is already 100% var-based, so the light theme is one palette-override block plus a handful of component tweaks. Monaco and xterm each get a second registered theme that follows the store value. Theme, panel geometry, and a transient `isDragging` flag live in the existing persisted layout store.

**Tech Stack:** Electron + React + TypeScript, Zustand (`persist`), Monaco (via `@monaco-editor/react`), xterm, Vite, Vitest.

## Global Constraints

- Theme default is `'dark'`; toggle is user-persisted via zustand persist under the existing `fcc-layout` key.
- Accent stays **terracotta**: dark `#d97a55`, light `#c9643c`.
- No new dependencies. No build-pipeline/tooling changes. No window/splash background changes.
- Every new CSS var must have a light override in `[data-theme='light']` (light thumb ≠ light bg).
- All transitions must fall under the existing `@media (prefers-reduced-motion: reduce)` block.
- Monaco/xterm/CSS are not unit-tested (existing policy); logic changes in the layout store get tests.
- `npm run typecheck` and `npm run test` must stay green after every task. This repo is **not** a git repo yet — no commits; the "commit" steps are replaced with a verify step.

- [ ] **Step 1: Implement the theme + chord + dragging in App.tsx**

Read `theme`, `isDragging` from the store:

```tsx

```

```tsx

}, [theme]);
```

Extend the existing keyboard effect — the chord handler (independent of the ctrl-key early return):

```tsx
const pendingChord = useRef<string | null>(null);

useEffect(() => {
  const onKey = (e: KeyboardEvent) => {
    // Theme chord: Ctrl+K then Ctrl+T (reset on any other key).
    if (e.ctrlKey && e.key.toLowerCase() === 'k') {
      e.preventDefault();
      pendingChord.current = 'k';
      return;
    }
    if (pendingChord.current === 'k' && e.key.toLowerCase() === 't' && !e.ctrlKey && !e.metaKey && !e.altKey) {
      e.preventDefault();
      pendingChord.current = null;
      toggleTheme();
      return;
    }
    pendingChord.current = null;

    if (!(e.ctrlKey || e.metaKey)) return;
    if (e.code === 'KeyB') {
      e.preventDefault();
      toggleSidebar();
    } else if (e.code === 'Backquote' && !e.shiftKey) {
      e.preventDefault();
      toggleTerminal();
    } else if (e.code === 'Backquote' && e.shiftKey) {
      e.preventDefault();
      toggleChat();
    } else if (e.code === 'KeyJ') {
      e.preventDefault();
      toggleTerminal();
    }
  };
  window.addEventListener('keydown', onKey);
  return () => window.removeEventListener('keydown', onKey);
}, [toggleSidebar, toggleChat, toggleTerminal, toggleTheme]);
```

Note: `toggleTheme` must be selected from the store and added to the effect deps. The root `<div className="app">` becomes:

```tsx
<div className={`app${isDragging ? ' dragging' : ''}`}>
```
